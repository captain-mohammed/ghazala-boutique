# بوتيك غزالة — GHAZALA BOUTIQUE

**أناقة تمشي بخطى واثقة** — نظام إدارة المخزون والمبيعات مصمم خصيصاً لبوتيك غزالة.

تطبيق PWA يعمل **بدون إنترنت 100%** على هاتف أندرويد. كل البيانات تبقى في جهازك.

![Ghazala Boutique](readme-header.png)

## المميزات

- 🔒 **قفل برقم سري** — يُعيَّن عند أول فتح
- 🏠 **لوحة رئيسية حيّة** — أرقام متحركة، تنبيهات نقص ونفاد المخزون، مخزون راكد
- 👠 **المخزون** — إضافة موديلات بسرعة (كود تلقائي GHZ-0001)، بحث وفلاتر، سجل حركات لكل موديل
- 🛍️ **بيع سريع** — سلة، باركود الشحنة، أجور توصيل تلقائية (5,000 د.ع افتراضياً)
- 📊 **تقارير** — اليوم/أسبوع/شهر، الأكثر مبيعاً، مخزون راكد، رسم بياني لآخر 14 يوم
- ✅ **الجرد** — عدّ فعلي مع تطبيق الفروقات بسجل كامل
- 💾 **نسخ احتياطي** — JSON كامل + تصدير Excel
- 🎨 **ثيم زجاجي** بهوية بوتيك غزالة (نبيتي/ذهبي/عاجي)

## التشغيل

```bash
npm install
npm run dev       # تطوير
npm run build     # نسخة الإنتاج في dist/
npm run preview   # معاينة النسخة النهائية
```

## تثبيته على الهاتف

1. ارفع مجلد `dist/` على GitHub Pages (أو أي استضافة ثابتة HTTPS)
2. افتح الرابط من Chrome على الهاتف
3. قائمة Chrome ⋮ ← **إضافة إلى الشاشة الرئيسية**
4. انتهى — التطبيق سيعمل بدون إنترنت من بعدها

## النسخ الاحتياطي

من التطبيق: **المزيد ← النسخ الاحتياطي** — خذ نسخة JSON أسبوعياً (تذكير تلقائي مدمج).
مسح بيانات المتصفح يمسح قاعدة البيانات — النسخة الاحتياطية هي الحماية الوحيدة.
